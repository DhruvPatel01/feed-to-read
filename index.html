Text.all (not . isAlphaNum)) . Text.words The wordCount function takes a Pandoc tree data structure, and recursively traverses it to get the count of textual words. For raw HTML code embedded in the tree, it parses the HTML code using the tagsoup library, and extracts the inner text after removing the tags. The words are counted after removing words that are composed of only punctuation. The readingTimeEstimateMinutes function then divides the word count by a words-per-minute (wpm) parameter — that I’ve set here to 220, close to the average reading speed of literate adult humans — to return the reading time estimate in minutes. You can change the wpm parameter as per your liking. That’s it. I hope this is helpful to you. Like, share, or comment on this post on Mastodon.
